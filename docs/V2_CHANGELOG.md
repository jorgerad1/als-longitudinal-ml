# Changes in ALS Longitudinal ML v2.0.0

## New in version 2

- Compact revised retrospective T1/T2 representation: 14 variable-level changed flags, seven observed-pair proportions and three signed numerical differences.
- Canonical mapping from 36 publicly documented aliases into five potentially overlapping activity groups, with eight compact text descriptors.
- Standalone offline JSON parsing and identifier alignment for schema-guided text extraction outputs.
- Nested cross-validation for Elastic Net logistic regression, linear SVC and Random Forest, using train-only preprocessing.
- Group-preserving analysis of matched pairs, optional correlation-filter sensitivity, conditional bootstrap, paired permutations and Holm adjustment.
- Public synthetic examples and 52 unit tests for the software components.

## Previous version

The historical v1.0.0 release is archived at https://doi.org/10.5281/zenodo.22864706. Existing historical files are preserved without changing their content; v2 adds new components and updated documentation.
