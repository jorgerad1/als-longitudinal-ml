# Dataset access and responsible distribution

This is a **code and synthetic-example release**. It includes source files, configuration, tests, technical documentation and fabricated input/output examples.

The project retains source participant questionnaires and free-text clinical narratives in restricted institutional storage. Public test fixtures were designed as invented examples rather than extracts from clinical records.

Software releases are reviewed for unintended inclusion of credentials, institution-specific file paths and identifiable source material. The authors remain responsible for approving their release contents.

Historical outputs retained from v1.0.0 are identified separately from the v2.0.0 software demonstrations. See `docs/README_V1_HISTORICAL.md` and `docs/V2_CHANGELOG.md`.
