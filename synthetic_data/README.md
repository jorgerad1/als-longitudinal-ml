# Synthetic demonstration data

`synthetic_questionnaire.xlsx` contains entirely artificial records
created only to exercise the public software workflow.

The file:

- contains no real participant or patient records;
- contains no transformed, perturbed, anonymized, or pseudonymized
  version of the restricted clinical dataset;
- was not generated by fitting distributions to the private cohort;
- uses fictitious identifiers of the form `SYN0001`;
- uses deliberately artificial, deterministic structured values;
- contains invented free-text questionnaire responses;
- uses an artificial balanced CONTROL/ELA outcome solely for software
  testing.

The `TXT_*` fields are deterministic synthetic stand-ins for
text-derived habit indicators. They allow the compact feature
construction and machine-learning pipeline to be demonstrated without
calling an external LLM API.

The synthetic dataset is suitable for testing software execution only.
It cannot reproduce or validate the numerical results reported in the
article.
